# Professional-Interactive-Data-Auditor-Dashboard
Professional Interactive Data Auditor &amp; Dashboard
Professional Interactive Data Auditor & Dashboard
Program ini dirancang untuk mensimulasikan alur kerja seorang Data Analyst profesional:

Data Ingestion: Mengunggah file CSV atau Excel.
Data Quality Audit: Memeriksa kualitas data (missing values, duplikasi, anomali) dan memberikan peringatan berkode warna.
Interactive Visualization: Membuat chart interaktif menggunakan Plotly yang dapat disesuaikan oleh pengguna secara real-time.
